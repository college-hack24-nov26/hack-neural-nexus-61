# CropNex AI

### AI-Powered Crop Disease Detection and Smart Agriculture Monitoring

CropNex AI is a smart agriculture solution designed to help farmers
identify crop diseases, monitor environmental conditions, and receive
actionable agricultural recommendations.

## Core Features

- AI-based crop disease detection.
- Pest detection (subject to model availability).
- Real-time soil moisture monitoring.
- Temperature and humidity monitoring.
- Smart agricultural recommendations.
- Dashboard for monitoring crop health and sensor readings.

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- SQLite
- SQLAlchemy

### Machine Learning
- PyTorch
- Open-source machine learning models

### IoT
- ESP32
- DHT11 Temperature and Humidity Sensor
- Capacitive Soil Moisture Sensor
- Wi-Fi Communication
